# UWONavi
A re-creation of the beloved GVONavi app, for use with Uncharted Waters Online.

This app uses the "Survey" skill's coordinates to map and track position on a 4096x2048 map. The target map can be changed in the config file (UWONavi.ini).

Config File attributes and defaults are explained in the file.

Be sure to set the ResolutionX/Y to your game's resolution, which is configured in UWO's Launcher Settings.

When the app is first launched, you will pick which UWO instance it will pay attention to (and you can reset this by pressing 'l'). This means you don't have to run Survey on your active character.

IMPORTANT: For now, windows scaling must be 100%. You can try with more or less, but I can't promise the OCR will be able to read the game coordinates.

Default Hotkeys:
r = Re-centre View
c = Clear Track History
l = Lock to new game instance
